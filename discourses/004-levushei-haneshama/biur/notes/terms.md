# מונחים — terms as this הגהה uses them (working lexicon)

Each entry: the term · what it means here · the line it rests on (address in sources/). Claude's reading;
"?" marks what is not settled. Abbreviations are opened in `abbreviations.md`.

| מונח | פירושו כאן | על מה נסמך |
|---|---|---|
| נר"ן (נפש רוח נשמה) / "הצורה" / "עצמות" | האדם עצמו, שלושת חלקי הנשמה הפנימיים (חיה ויחידה מקיפים, ואין כנגדם כלים) | ע"ח 26.1.2 "הצורה הוא העיקר הנקרא אדם"; 49.1.2; 49.4.2 "העצמות הם נר"ן" |
| כלים / גוף / "חומר" | האיברים שבהם מתלבשת הנשמה: שלושה כלים (מוח–לב–כבד; עצמות–גידין–בשר) | 41.1.2; 49.1.2; 26.1.2 |
| צלם | האמצעי בין הצורה לחומר; לבוש הצורה; "הבל דגרמי"; יצ"ט ויצה"ר; תרי"ג "איברים" שהם מלאכים; מספר ניצוצותיו = ימי חיי האדם | 26.1.2 |
| צלם דאימא / לבוש נה"י דאימא / "חותם" | הלבוש שבו נכנסים המוחין: נה"י של אימא (תבונה); ממנו "תרין דיוקנין" לנפשות; בו בחי' פנימי ובחי' מקיף | 26.2.1; 41.1.2 ("ג' כלים דתבונה הנקרא צ' דצלם... והוא לבוש אל הנר"ן"); 39.12.1 ("לבוש מאמא והוא החותם") |
| חשמל | (א) חלק הצלם הנשאר מקיף מבחוץ; גימטריא "מלבוש"; (ב) עור התבונה שעל עור ז"א, המגן מיניקת החיצונים; "כתנות אור" של אדה"ר; (ג) "הטוב שבקליפת נוגה שבכל עולם" | 26.2.1; 41.1.2; 42.4.1; 49.1.2 (בשר, "המקיף לכל הכלים"); 49.4.2 |
| קליפת נוגה | הקליפה הרביעית, הדקה, הסמוכה לקדושה: טוב ורע מעורבים (בבי"ע; באצילות טוב); "עור"; "משכא דחויא", "כתנות עור"; בה נשארו רפ"ח הניצוצין שלא נתבררו; ממנה נפש הבהמית דישראל | 49.2.1; 49.3.1; 41.1.2; 42.4.1 |
| הבל דגרמי | הניצוצות (מרפ"ח) שנשארו בכלים הנשברים; הוא הצלם; ובעיבור ויניקה — מה שבתוך הכלים קודם שנכנסים נר"ן דגדלות | 26.1.2; 41.2.1; 42.4.1 |
| לבושים (של הנשמה) | הלבושים של זוהר ויחי (רכ"ד): מימי האדם ומצוותיו; בע"ח: הם הצלם והכלים ("גופא דילהון") שנפלו לנוגה בחטא אדה"ר, ומתבררים ע"י תורה ומצוות | זוהר ח"א רכ"ד; ח"ב ר"י, רכ"ט; ע"ח 49.4.2, 49.5.1; 26.1.2 |
| בירור | הפרדת הטוב (ניצוץ הקדושה) מן הרע שנתערב בו; "לצרף ולברר וללבן" | 49.5.1; 26.1.2; פע"ח שער התפלה 7.1 |
| ז' מלכים / רפ"ח ניצוצין | המלכים שמתו (שבירת הכלים); קדושתם נתבררה ונעשו ממנה העולמות, ומה שנשאר — הנשמות, ואח"כ שאר הנבראים | 39.1.2; 39.2.1; פע"ח 7.1–7.2 |
| מ"נ (מיין נוקבין) | מה שעולה מלמטה אל הנוקבא לעורר זיווג: "הם הנשמות הקדושות ממש... אשר תוך מלכים אלו"; גבורות; שם ב"ן | 39.1.2; 39.11.7–8 |
| מ"ד (מיין דכורין) | מה שיורד מן הזכר כנגדם: החסדים; שם מ"ה; "המשכת האור דלעילא" | 39.1.2; 39.11.8 ("ואז יורדין החסדים מן הזכר"); פע"ח 7.4 |
| נוקבא דז"א / מלכות / "הנקבה העליונה" / רחל | הפרצוף המקבל; בה עולות הנשמות למ"נ ובה מתעברות ומצטיירות קודם ירידתן לגוף | 39.2.1–2; שעה"ג 12.5 |
| עיבור הנשמה במלכות | שהיית הנשמה שעלתה מן הקליפות "במעי המלכות" להיטהר: י"ב חודש / ט' / ז' / מ' יום / ג' ימים לפי מדרגתה | שעה"ג 12.5–12.7; 39.6 |
| נשמות חדשות / שלא נכללו באדה"ר | מדרגה א': שלא באו בכלל אדה"ר (או שנסתלקו קודם החטא), "חדשות אמיתיות"; שאר המדרגות היו כלולות בו ונפלו לקליפות | שעה"ג 6.2–6.3; 7.1; 12.2–12.4; 39.2–39.5; ספר הגלגולים פ"ז (חסר עדיין) |
| פנימיות / חיצוניות (העולמות) | חיצוניות = העולמות עצמם, המעשה; פנימיות = הנשמות, הדיבור (תפילה ותורה); הכוונה — נשמה לשניהם; "החיצוניות של כל עולם הוא בחי' חלק העשיה שבו" | ע"ח 40.1.2; 40.2.1; 40.3.1 |
| אור פנימי / אור מקיף | האור הנכנס בכלי / הנשאר סביבו; בצלם: צ' פנימי, ל"מ מקיפים; "המעשה — או"פ, הברכה — או"מ" | 26.2.1; 40.2.1; פע"ח 7.34 |
| עיבור, יניקה, מוחין (דגדלות) | שלוש מדרגות גידול הפרצוף (ג' כלול בג'; ו"ק; י"ס) | 26.2.1; 40.1; 41.2.1; פע"ח ציצית 2.2 |
| אימא / בינה / תבונה; "עוה"ב" | בינה נקראת עולם הבא; "אמא מקננא בכורסייא" = מאירה בבריאה | 47.3.1; זוהר ח"ב ר"י ע"ב ("עלמא דאתי") |
| מו"ס דא"א; י"ג חיוורתא דגלגלתא | מוחא סתימאה (חכמה סתימאה) של אריך אנפין; י"ג הלבנוניות שבגולגלתא שבין שער לשער | ע"ח 13.5.1; 39.1.2 ("המחשבה עליונה שהיא חכמה סתימאה... האיר בהם ועי"ז נבררו") |
| זו"נ דאצילות בבי"ע בחול | בימי החול יורדים העולמות ומתלבשים זה בזה כדי לברר; רק ז"א, הזכר, מברר | פע"ח 7.4–7.5; ע"ח 41.3.2 |
| "אצילות ממש שבבי"ע" | חלק האצילות המתפשט בבי"ע (כלי ז"א המתלבשים שם) | 41.3.2 ("חלק האצילות מתפשט בכל בי"ע"); 44.5 (נשמת זו"נ דבי"ע = כלי זו"נ דאצילות) |
| ג' כלים דז"א דאצילות (פנימי / אמצעי / חיצון) | כל ספירה: שלושה כלים ושלושה שמות; הפנימיים נעשים נשמה לבריאה, האמצעיים ליצירה, החיצוניים לעשיה | 44.3; 44.5.1, 44.5.4, 44.5.8; 49.1.2 |
